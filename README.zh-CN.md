# Part B VRP Writing

[English](README.md) | **简体中文**

**版本：v1.0.0** · [版本说明](CHANGELOG.md)

面向拟投 **Transportation Research Part B: Methodological** 的车辆路径及相关交通运筹论文的写作 skill。

本 skill 将常见写作问题转化为可执行流程：**定位问题 → 判断依据 → 落实修改 → 复查结果**。从经过核对的论文中学习组织与解释方法，同时保留当前稿件自己的研究背景、假设和证据。

skill 的执行指令使用**英文**。通过上方链接切换 README 语言；修改后的论文和解释可使用中文或英文。

## 为什么做这个 skill

语法正确的稿件，仍可能让读者不清楚路径规划问题为什么重要、某组约束实际保证什么，或某项实验能说明什么。反复要求“按 Part B 风格写”，并没有指出具体问题和修改方法。

本 skill 将这些写作问题记录为可复用的判断与修改流程，重点处理交通运筹论文中的决策权衡、数学定义、算法逻辑，以及贡献的证据。具体研究背景和结果由每篇稿件提供。

## 覆盖内容

| 环节 | 主要处理的问题 |
| --- | --- |
| 标题、摘要与结论 | 主张范围是否与实际研究及证据一致 |
| 引言与贡献 | 如何从决策困难建立研究动机，说明新增了什么 |
| 文献综述 | 如何组织研究关系、假设与适用边界 |
| 问题描述与符号 | 先建立系统理解，再引入符号，并方便查阅定义 |
| 数学模型 | 连贯呈现模型，按顺序解释目标与约束组 |
| 算法与证明 | 交代整体框架、状态更新、伪代码、条件与保证 |
| 实验与结果 | 让每项比较对应研究问题和有证据支持的结论 |
| 图形与表格 | 选择绘图逻辑、表格内容、缩写与配色 |
| 修改与一致性 | 检查受影响的定义、引用、主张及双语对应内容 |

## 一个修改示例

**以下仅为说明性示例。** 这是为本说明编写的小型数学例子，不是参考论文原文，也不是对 skill 效果的实证评估。

假设模型包含客户集合 $C\subseteq V$、节点集合 $V$ 和车辆集合 $K$。二元变量 $x_{ij}^{k}$ 等于 1 时，表示车辆 $k$ 使用弧 $(i,j)$。其中一组约束为：

$$
\sum_{k\in K}\sum_{j\in V\setminus\{i\}}x_{ij}^{k}=1,\qquad i\in C.
$$

**修改前：**“这些约束保证路径可行。”

**判断：**文字的含义超过了所列公式。这组约束规定客户出弧的数量，并没有建立路径可行所需的全部条件。

**修改后：**“这些约束要求在整个车队中，每个客户恰有一条出弧。”

**复查：**对照实际模型确认索引集合和变量含义，再按各组约束实际保证的关系解释其余公式。修改贡献或结果分析时也采用相同过程：先确定证据支持的含义，再调整语言。

## 如何工作

1. **定位问题：**指出需要处理的句子、公式、图形、表格或章节。
2. **判断依据：**结合实际稿件、证据和对应写作规则判断问题。
3. **落实修改：**在指定范围内提供替换正文或编辑后的文件。
4. **复查结果：**核对修改及直接受影响的定义、主张和引用。

| 任务 | 需要提供的材料 | 预期输出 |
| --- | --- | --- |
| 规划论文或章节 | 研究问题、已确定方法、已有发现及限制 | 论证提纲、章节功能及缺失信息 |
| 修改正文 | 最新段落、相关证据及措辞或范围限制 | 替换正文与实质修改的简短理由 |
| 检查模型或算法描述 | 定义、公式、伪代码及相关实现细节 | 问题位置、判断依据和修改建议 |
| 改进图表 | 数据或源文件、比较问题及视觉偏好 | 有依据的设计或修改；绘图使用当前可用的合适工具 |
| 学习参考论文 | 论文或链接，以及要学习的写作问题 | 已核对的位置、组织功能及可迁移的做法 |

持续修改同一篇稿件时，可使用[上下文模板](assets/manuscript-context.template.md)记录已知事实、主张与证据、已核对来源和作者偏好。填写后的记录保存在稿件项目内。

## 设计原则

- 区分必须遵守的学术要求、可以调整的写作习惯和作者偏好。
- 区分现实事实、研究假设、实验设置与解释。
- 保留真实贡献，同时让结论范围与证据匹配。
- 尊重“只改表达、不加实验”等明确要求。
- 声称参考某篇文章之前，先核对原文；判断颜色和版式之前，实际查看图像。
- 不把某篇稿件的业务背景、参数和算法选择写成通用规则。

## 文献依据与图形偏好

[核对记录](references/partb-evidence.md) 包含 Su 等（2023）、Sun 等（2018）和 Zamal 等（2025）的部分内容，明确区分实际图像检查与仅文字核对、作者稿与出版稿。这些样本支持具体写法的选择，不代表对 Part B 写作惯例的全面调查。

本 skill 保留作者希望**图形颜色更明亮**的偏好。新图以白底、黑色标签作为可调整的制作默认，并根据要表达的信息选择颜色、形状和线型。不声称 Part B 要求某套固定色板，也不将未经验证的色号说成论文原图的精确配色。

## 适用边界

这是独立的写作资源，不宣称与期刊或出版商存在官方关联。它不代替算法实现、实验运行或数学证明，也不保证录用。涉及现行投稿要求时，仍需核对期刊官方指南。

仓库仅包含指令、空白模板和附来源链接的原创核对笔记，不分发参考论文全文或原图。后续完善 skill 时，具体稿件的数据和填好的上下文记录应保留在稿件项目内；新增的文献观察与作者偏好应分别说明。

1.0.0 版不包含自动检查稿件的脚本、现成的 LaTeX 或绘图模板，也不包含行为评估套件。文件格式检查通过，并不证明写作质量或数学正确性。
